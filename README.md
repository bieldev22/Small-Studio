# Small Studio Barber

Site institucional responsivo em React, TypeScript e Vite, com Motion para animações e Lucide para ícones funcionais.

## Executar

```bash
npm install
npm run dev
```

Validar a versão de produção com `npm run build` e pré-visualizá-la com `npm run preview`.

## Conteúdo real pendente

Edite `src/siteConfig.ts` para inserir texto de apresentação, história e missão confirmadas, telefone de WhatsApp com código do país e DDD (somente dígitos), URL do Instagram, endereço, arquivo e poster do vídeo e fotografias reais. O WhatsApp gera um link de conversa com mensagem inicial; não existe sistema de agendamento integrado.

As três fotografias atuais são imagens externas de referência, identificadas como provisórias na galeria. Substitua os itens de `portfolio` pelos arquivos reais em `public/assets/images/` e atualize seus caminhos e textos alternativos. Coloque o vídeo e seu poster em `public/assets/videos/` e `public/assets/images/`, respectivamente; use caminhos como `/assets/videos/ambiente.mp4` em `environmentVideo`.

O workspace não contém os arquivos de identidade exportados: a marca e o símbolo foram consultados nas imagens do PDF anexadas à conversa. Antes da publicação, substitua a reprodução geométrica do símbolo e o favicon pelo vetor oficial, caso esteja disponível. Não há história, missão, contato, endereço, trabalhos ou gravação do espaço confirmados neste momento; esses conteúdos não foram inventados.
